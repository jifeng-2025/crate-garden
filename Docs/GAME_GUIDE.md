# 游戏教程 · 从第一只箱子开始

[返回项目首页](../README.md)

这份教程面向第一次玩推箱子的玩家。先完成前两关，练习撤销，再尝试多箱关卡，最后制作自己的谜题。

## 1. 认识棋盘

你控制的是白色外壳的小机器人。黄色木箱可以推动，绿色圆环是目标，青绿色石块是不能穿过的墙。

**胜利条件：把每一只箱子都推到目标上。** 箱子到达目标后会变绿。右侧 `CRATES DELIVERED` 表示已送达数量，例如 `1 / 3` 就是三个箱子中已有一个就位。

![棋盘示例：机器人、木箱、目标环和绿色完成箱](Screenshots/03-playing.png)

只需要记住三个规则：

1. 机器人一次走一格，不能斜走或穿墙。
2. 向箱子方向移动时，如果箱子后面的格子空着，就能把它推过去。
3. 不能拉箱子，也不能同时推两只。每次推之前，先想好下一次能否绕到箱子后面。

## 2. 开始第一关：两次向右

从主菜单点击 **All levels**，找到 **01 · First delivery**，点击卡片上的 **Play**。新存档也可以直接点击主菜单的 **Enter the garden**。

第一关中，机器人、箱子和目标在同一行。下面只展示这一行的关键格子，图中文字是位置说明：

```text
开始：  [机器人] [箱子] [空地] [目标]
右移：  [ 空地 ] [机器人] [箱子] [目标]
再右：  [ 空地 ] [ 空地 ] [机器人] [已送达箱子]
```

操作步骤：

1. 点击游戏画面，让它接收键盘输入。
2. 按一次 **→** 或 **D**，推动箱子一格。
3. 再按一次 **→** 或 **D**，将箱子推到目标上。
4. 出现 **Garden complete**，这一关完成；记录应为 **2 moves / 2 pushes**。
5. 点击 **Next garden** 进入第二关。

练习时建议短按，一次只走一格。长按会连续移动。

## 3. 学会反悔：撤销与重做

第一关通关后可以直接练习：

1. 按 **Z** 或点击 **Undo last move**，撤销最后一次推动，回到未通关状态。
2. 按 **Y** 或点击 **Redo**，重做刚才的推动，再次完成关卡。
3. 按 **R** 或点击 **Restart garden**，将当前关卡恢复到初始布局。

撤销不止能退一步，可以连续使用。撤销后如果走了另一条路线，旧路线的重做记录会清空。已经保存的正式通关成绩不会因为撤销或重玩而丢失。

## 4. 第二关：绕到箱子的另一侧

第二关 **Around the corner** 的目标在右上角。机器人开始时站在箱子下方；需要先向上推，再绕到左边向右推。

从初始局面依次按：

**↑、←、↑、→、→**

| 第几步 | 按键 | 为什么这样走 |
| --- | --- | --- |
| 1 | ↑ / W | 从箱子下方向上推一格，让箱子到达目标所在的那一行 |
| 2 | ← / A | 向左绕行，为改变推动方向腾出位置 |
| 3 | ↑ / W | 走到箱子左侧 |
| 4 | → / D | 向右推动一次 |
| 5 | → / D | 再推一次，送到右侧目标 |

完成时应为 **5 moves / 3 pushes**。这里的关键不是连续追着箱子走，而是先找到下一次推动时机器人需要站的位置。

## 5. 多箱关卡怎么想

从第三关开始，需要照顾不止一只箱子。推荐在每次推动前问自己：

- 箱子到了那里，我还能绕到它的另一边吗？
- 它会不会堵住通道，让另一只箱子无法通过？
- 这个格子是不是没有目标的墙角？

可以先选择路线最清楚的一只箱子，但不要为了先完成它而堵住其他箱子的路线。箱子变绿只表示当前在目标上，并不会被锁住；必要时仍可以推开它再调整。

第七关 **Three wishes** 的截图中，中间箱子先被向上推动两格，右侧显示 `1 / 3`。之后需要绕到剩余两只箱子的下方继续推动。

## 6. 卡住了怎么办

| 情况 | 可以尝试的办法 |
| --- | --- |
| 箱子进入没有目标的死角 | 按 Z 撤销到进入死角之前；箱子不能拉出来 |
| 两只箱子挤在一起，推不动 | 换方向绕行，或撤销形成堵塞的那一步 |
| 不知道下一步 | 点击 **A gentle hint**，查看右侧的方向建议 |
| 提示说当前局面无解 | 退回几步重新安排路线，必要时重开 |
| 提示只有通用建议 | 可能达到搜索预算；不代表已经判定无解 |
| 按键没有反应 | 点击游戏画面；若暂停，先点击 Resume；若已通关，可继续下一关或撤销 |
| 想休息 | 按 Esc 或点击 Pause；恢复后继续当前局 |

右侧 `moves` 包含普通行走和推箱动作，`pushes` 只统计推动箱子的次数。计时只是结算信息，游戏没有倒计时失败条件。

## 7. 通关与继续游戏

全部箱子到位后，会显示结算界面：

![通关界面：步数、推箱次数、下一关与重玩入口](Screenshots/04-complete.png)

- **Next garden**：进入下一关；最后一关完成后返回关卡列表。
- **Play again**：重新挑战这一关，尝试减少步数。
- **Undo last move**：回到最后一次推动之前。
- **All levels / The journey**：查看关卡及最佳成绩。

完成进度和最佳成绩自动保存在本机。退出游戏不会保存当前棋盘的每一步；下次进入该关时会从初始布局开始。主菜单的 **Continue journey** 会进入尚未完成的关卡，而不是恢复上一次的中途局面。

## 8. 制作你的第一个关卡

从主菜单点击 **Level workshop**。默认草稿已经有一个机器人、一个箱子和一个目标，可以直接用它熟悉流程。

![关卡编辑器：笔刷、校验、保存与试玩](Screenshots/05-workshop.png)

1. 在 **GARDEN NAME** 输入关卡名称。
2. 选择 **Wall**，在远离机器人和箱子路线的空格上点一下，放置一块墙。
3. 如果位置不合适，点击 **Undo paint** 撤销；也可右键清空该格。
4. 点击 **Validate**。结构有问题时，先按提示修正；达到求解预算时，继续用试玩确认。
5. 点击右上角 **Playtest**，用方向键验证关卡确实能完成。
6. 按 **Esc** 或点击 **< Workshop** 返回编辑；刚才的草稿仍在。
7. 点击 **Save to collection** 保存。
8. 返回主菜单 → **All levels** → **Your creations**，即可找到并正式游玩。

笔刷对应关系：

| 英文笔刷 | 用途 |
| --- | --- |
| Wall | 墙，阻挡机器人和箱子 |
| Floor | 空地，也可用于清除格子上的内容 |
| Goal | 目标 |
| Crate | 箱子 |
| Player | 机器人起点；放到新位置时会移除旧起点 |

边框必须保持封闭，棋盘中恰好有一个机器人，箱子和目标数量必须相等且至少各一个。在目标上再放箱子或机器人，会保留下面的目标。

试玩不会计入正式成绩；需要保存后从 **Your creations** 进入，才会记录成绩。修改已保存关卡的布局后，旧成绩会清除；只改名字则保留成绩。

## 9. 分享与导入

**分享给别人：** 编辑器中点击 **Export** → **Copy to clipboard**，把完整 JSON 文本交给对方。

**导入别人作品：** 点击 **Import**，粘贴完整 JSON，再点击 **Import level**。导入后先试玩，再保存到收藏。导入会分配新的 ID，不覆盖现有收藏；但会替换当前编辑草稿，因此应先保存正在编辑的内容。
